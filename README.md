# Roblox Grapple Simulator

This project is a Roblox script that simulates a grapple hook system, allowing players to remove their legs and adjust their hitbox to make them invulnerable while still interacting with the environment and other players. The script enables grappling to objects and people, providing a unique and immersive gameplay experience.

## Install

1. Open Roblox Studio.
2. Create a new Roblox game or open an existing one.
3. In the Explorer window, navigate to the ServerScriptService.
4. Right-click on ServerScriptService and select "Insert Object" > "Script".
5. Name the script "GrappleSimulator.server.lua".
6. Copy and paste the contents of the provided `GrappleSimulator.server.lua` file into the script.

## Use

1. Start the Roblox game.
2. Players will automatically have their legs removed and their hitbox adjusted upon spawning.
3. To grapple to an object or person, left-click on the target with your mouse.
4. The player will be pulled towards the target using a grapple hook effect.
5. Players can still interact with the environment and other players while being invulnerable.
